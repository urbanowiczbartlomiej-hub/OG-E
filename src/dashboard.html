Daily Run

Each route sends a fixed micro-fleet from one or more source bodies (planets and/or moons) to an ordered list of targets. Standing on any source, the Send zone of the Daily Run button scatters the fleet to the targets in order. Pick everything from your own planets and moons — nothing to type. The collect target is set in-game by holding the Send All zone of the button, not here.

Advanced — text import / export (DSL)

One route per line: <src>, … = <ship>x<count> -> <target>, … — ship is an alias (SC/LC/PF — Small cargo / Large cargo / Pathfinder) or raw id; count takes a k suffix (×1000); a trailing m marks a moon (on either side). Editing here and pressing Apply replaces the cards above. This text is what syncs across devices.
