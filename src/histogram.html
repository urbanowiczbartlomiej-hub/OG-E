Setup — step by step

  1. In OG-E settings (in the game), paste a GitHub token with gist scope and turn on cloud sync. The reminder feature reuses that same token and private gist.
  2. Generate an ntfy topic above. Install the ntfy app on your phone (Android / iOS) and subscribe to that exact topic. Your smartwatch will mirror the notification automatically.
  3. Deploy the Cloudflare Worker (one-time). It needs the gist id below as the GIST_ID variable and your token as the GIST_TOKEN secret, with a cron trigger of * * * * * (every minute). Full wrangler.toml + index.js were provided separately.
  4. Open a game tab and send your expeditions. OG-E reads the return times and writes them to the gist — confirm they appear in the live preview below.
  5. Flip Enable reminders on. From now on, when a wave is overdue and the time is inside your allowed window, you'll get a push until you re-send (or until the cap).

How it works

A "wave" is a group of expeditions sent together that come home together. OG-E reads each expedition's return-flight from the in-game event list (the same passive read that powers the green planet dots) and clusters returns that land within a few minutes of each other into one wave. Sending in two batches a while apart produces two independent waves, each reminded on its own.

The extension only sets the deadline. It writes, per wave, the time the fleet returns home (nextWaveAt) plus your config into the gist, then stops watching — it does not need to stay open.

The Worker watches the clock. Every minute it reads the gist; if reminders are on, the time is inside your window, and a wave is overdue, it sends a push via ntfy and bumps that wave's counter. It repeats until you re-send (which pushes the return time into the future) or you turn reminders off.

Identity is the set of origin planets, so re-sending from the same planets is recognised as the same wave and its counters reset cleanly.
