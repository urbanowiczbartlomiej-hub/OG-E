Colony Size Histogram

Field sizes of planets you have personally visited (recorded the first time you opened each overview page). No new data is requested — this is a read-only view of data already stored locally on this device.

Galaxy Observations

Per-system summary of positions you have navigated past in the in-game galaxy view. Data was recorded only for galaxy pages you yourself opened. Filtered by the target positions list from settings (only those positions count toward the stats below).

Free Positions — longest confirmed empty runs

For each scanned galaxy, the longest contiguous run of systems whose chosen slot is confirmed empty. An unscanned system, or a scanned system with a different status, breaks the run — reported lengths are a lower bound on what actually exists, so they only grow as you keep scanning.
